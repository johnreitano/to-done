# Tech Stack

## Backend

### Framework
- **Ruby on Rails** — Full-stack web application framework providing both backend API and frontend rendering

### Language
- **Ruby** — Primary programming language (use latest stable version supported by Rails)

### Database
- **PostgreSQL** — Primary relational database for persistent data storage

## Frontend

### Templating
- **ERB (Embedded Ruby)** — Rails default templating engine for server-rendered views

### Styling
- **CSS** — Standard stylesheets (Rails asset pipeline or import maps)

### JavaScript
- **Hotwire (Turbo + Stimulus)** — Rails default for modern, lightweight interactivity without heavy JavaScript frameworks

## Infrastructure

### Hosting
- **Heroku** — Platform-as-a-service for application hosting and deployment

### Database Hosting
- **Heroku Postgres** — Managed PostgreSQL addon provided by Heroku

## Development Tools

### Version Control
- **Git** — Source code version control

### Package Management
- **Bundler** — Ruby dependency management via Gemfile

### Testing
- **Minitest** — Rails default testing framework (or RSpec if preferred)

## Configuration

### Environment Management
- **Rails Credentials** — Encrypted credentials for sensitive configuration
- **Environment Variables** — Runtime configuration via Heroku config vars

### Asset Pipeline
- **Propshaft or Sprockets** — Rails asset compilation and serving
