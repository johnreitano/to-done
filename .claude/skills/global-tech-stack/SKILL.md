# Global Tech Stack

## When to use this skill:
- When selecting libraries or tools for a new feature
- When ensuring code follows the project's technology conventions
- When onboarding or reviewing architecture decisions

## Stack Reference

### Framework & Runtime
- **Application Framework:** Ruby on Rails (full-stack)
- **Language:** Ruby (latest stable)
- **Package Manager:** Bundler (Gemfile)

### Frontend
- **Templating:** ERB (Embedded Ruby)
- **JavaScript:** Hotwire (Turbo + Stimulus)
- **CSS:** Standard CSS via Rails asset pipeline

### Database & Storage
- **Database:** PostgreSQL
- **ORM:** ActiveRecord

### Testing & Quality
- **Test Framework:** Minitest
- **Linting:** RuboCop (recommended)

### Deployment
- **Hosting:** Heroku
- **Database Hosting:** Heroku Postgres
