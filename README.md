# To-Done

## some initial requirements

- create a to-do app in ruby on rails called to-done. 
- there is no authentication.
- the only features are the ability to add, update and delete to-do items.
- the target users are individuals who need a simple to-do list.
- the tech stack is ruby on rails for both front and backend with postgresql.
- the hosting is on render.com.
- please use reasonable defaults for any other questions.
